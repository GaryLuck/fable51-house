# House Playground

A 3D virtual playground for a six-year-old: explore a 1960s single-story house (den, two bedrooms, kitchen, dining room, bathroom) and play with the dog in the picket-fenced yard.

Everything lives in **`index.html`** — a single self-contained file (Three.js is embedded, no network needed after the page loads).

## Play it

Open `index.html` from any web server (or GitHub Pages). Keyboard: **WASD / arrows** to walk, **drag** to look, **space** to jump. Touch: **drag on the left** to walk, **drag on the right** to look, **tap the dog** to make him bark, **⬆︎ button** to jump.

## Install on an iPad

1. Host `index.html` over HTTPS (GitHub Pages works) and open it in Safari.
2. Tap **Share → Add to Home Screen**.
3. Launch it from the home-screen icon — it runs full screen in landscape.
